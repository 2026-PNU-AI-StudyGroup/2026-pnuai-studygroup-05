## 1. 프로젝트 소개

### 1.1. 개발배경 및 필요성
부산 동구 초량·좌천동 **망양로 산복도로 일대**는 급경사 지형에 고령 인구가 밀집한 지역입니다. 심정지가 발생하면 4~6분 안에 비가역적 뇌손상이 시작되지만, 이 지역은 지형·도로 여건상 구급차 도달과 처치가 늦어지기 쉽습니다.

- **발생 확률이 높다.** 2024년 급성심장정지 33,034건 중 **70세 이상이 52.9%**(70~79세 21.2%, 80세 이상 31.8%)를 차지합니다. 고령 인구가 많은 산복도로는 구조적으로 발생 위험이 높습니다.
- **목격되기 어렵다.** 일반인 CPR 시행 시 생존율은 15.3%로 미시행(5.6%) 대비 약 4배입니다. 독거 비율이 높으면 "쓰러져도 발견되지 않아" 초기 대응이 지연됩니다.
- **필요한 곳과 설치된 곳이 반대다.** 현행 AED 법정 의무설치 기준(「응급의료에 관한 법률」 제47조의2)은 **밀집도(연면적·세대·근로자·유동인구) 중심**입니다. 단독주택이 밀집한 산복도로에는 의무 대상이 사실상 없고, 오히려 부산역 인근 평지에 AED가 몰립니다. 실제로 야간 접근 AED의 표고 중앙값은 **13m**(평지)인 반면 고위험 집계구는 **52m**(산복도로 상단)로, 저지대 편중이 데이터로 확인됩니다.

즉, **가장 위험한 곳에 응급 자원이 가장 부족한** 구조적 불일치가 존재하며, 이를 데이터로 규명하고 개선안을 제시합니다.

<br/>

### 1.2. 개발 목표 및 주요 내용
데이터에 근거해 산복도로의 응급 취약성을 지도화하고, 골든타임을 지킬 수 있는 **AED 최적 배치안**을 도출합니다. 문제를 5개의 데이터 축으로 분해합니다.

| 축 | 이름 | 답하는 질문 | 상태 |
|:---:|:---|:---|:---|
| 1 | 수요 (응급 취약성) | 누가 위험한가 | ✅ 집계구 실측 완료 |
| 2 | 경사·도로망 | 어떻게 가는가 | ✅ 완전연결 그래프·경사비용 구현 |
| 3 | 이송 목적지 | 어디로 옮기는가 | ✅ 등급 교차검증 완료 |
| 4 | AED | 지금 무엇이 있는가 | ✅ 공백·MCLP 완료 |
| 5 | 검증 | 모델이 맞는가 | ⏳ 119 출동기록 미확보 |

**분석 단위:** 100m 격자(추정 배분)를 폐기하고 **집계구(실측, 78개)** 로 격상. 인구 기준시점 **2026-06**.

<br/>

### 1.3. 세부내용
- **응급 취약성 재정의:** **응급 취약성 = 발생 확률 × 목격 불가능성 × 도달 지연**. AED 배치 가중에는 **발생확률(75세+ 실측) × 도달지연**만 사용하고(A안), 목격 불가(독거)는 별도 조기발견 지표로 분리합니다. — *AED는 목격된 심정지만 살리므로.*
- **도로망을 그래프로:** OSM 차량망을 **유향 그래프**로 만들고, 표고·경사를 부여해 Dijkstra로 안전센터→현장 도달지연을 계산합니다. 여기에 **경사비용(오르막 페널티 유효거리, β=6)** 을 구현해 급경사 고지대의 도달 불리를 반영합니다.
- **이송 목적지 등급 분류:** 심정지 이송 대상인 **권역·지역 응급의료센터**만 후보로 한정(「응급의료법」 제2조제5호).
- **AED 최적 배치:** 야간 미커버 고위험 집계구를 수요로, 위험도를 가중치로 하여 **MCLP(최대 커버리지)** 로 신규 후보를 선정합니다.
- **실측 검증(예정):** 119 출동 기록·질병관리청 급성심장정지조사(OHCA)로 모델을 보정·검증합니다.

<br/>

### 1.4. 기존 방식 대비 차별성
- **밀집도가 아니라 도달지연·지형 기준.** 경사와 실제 도로 도달지연을 1차 기준으로 삼습니다.
- **방향 비대칭 경사 반영.** 오르막/내리막 이동비용이 다르다는 점을 그래프에 반영(`to_undirected` 금지). 경사비용은 **출동(등판) 방향의 오르막만** 페널티.
- **집계구 실측.** 100m 격자의 연령 '배분(추정)' 대신 ~500명 단위 실측 집계구로 산복도로 상/하단을 실제로 구분합니다.
- **"계산은 넓게, 해석은 좁게".** 그래프는 병원·안전센터·경계를 감싸는 볼록껍질 + 1.5km 버퍼로 넓게, 분석·배치는 대상지로 좁혀 수행(경계효과 방지).
- **근거의 투명성.** 출처 불명확 수치("순환회복률 6.6배" 등)는 보류하고 임계값 민감도로 대체합니다.

<br/>

### 1.5. 사회적 가치
- 응급의료 취약지(산복도로)의 **골든타임 사각지대**를 데이터로 가시화.
- 법정 기준으로 포착되지 않는 지역에 대한 **AED 우선 배치 근거** 제공.
- **재현 가능한 분석 방법론**을 제시해 유사 지형(부산 원도심 등)으로 확장 가능.

### 2.1. 시스템 구성도

```

  SGIS 집계구 경계            OpenTopoData           15000563 병원 API
  집계구 성·연령별 인구        SRTM 30m 표고          15000652 AED API
  주민등록(jumin 2026-06)     소방청 구급차           OpenStreetMap 도로망
        │                        │                       │
        └──────────┬─────────────┴───────────┬───────────┘
                   ▼                          ▼
        [전처리 · 좌표계 변환 5179→5186]   [OSM 차량 그래프 추출]
        집계구 조인 + 하이브리드 최신화       표고·경사·SCC 완전연결
                   │                          │

                                ▼
                 [Dijkstra 도달지연 (거리 + 경사비용 β=6)]

                [AED 야간공백(R=150m) × 위험도 → MCLP]
                                ▼
                      [신규 AED 후보 15개 · 통합지도]
```

## 3. 개발결과

### 3.1. 전체 시스템 흐름도
**인구는 그래프에 직접 들어가지 않고**, 도달지연이 계산된 뒤 "그 결과가 얼마나 중요한가"를 나타내는 가중치로 결합됩니다.

1. **그래프 계산** (인구 무관) — 경사·도로망 기반 도달지연 산출 (거리 + 경사비용)
2. **집계구에 도달지연 부여** — 중심을 최근접 노드에 스냅, 안전센터 최단
3. **인구 결합** — 정규화(75+ 실측·2026-06) × 정규화(도달지연) = **위험도**
4. **AED 야간공백** — 야간 접근 AED(R=150m) 미커버 & 고위험 집계구
5. **MCLP 최적화** — 위험 가중치로 신규 AED 후보 선정
6. **검증(예정)** — 119 출동·OHCA 데이터

<br/>

### 3.2. 기능설명 (축별 결과)

##### ` 축 1 — 수요 (응급 취약성) · 완료 `
- SGIS **집계구 성·연령별 인구**(78개)를 경계에 `TOT_OA_CD`(14자리 코드)로 조인 → **75세+ 실측**.
- **하이브리드 최신화:** 집계구 2024 내부 분포 유지 + 주민등록(jumin) 2026-06 동총량으로 스케일(동별 ×0.81~×1.25).
- 독거는 A안으로 위험도에서 분리. 위험도 = 정규화(75+) × 정규화(도달지연).
- **결과:** 초량·좌천 75+ 실측 4,781명. 최고위험 **초량6동(0.69)** > 좌천동 > 초량2동.

##### ` 축 2 — 경사·도로망 (그래프) · 완료 `
- OSM 차량망 → 유향 그래프. 표고(SRTM 30m) → 경사 `(끝−시작)/길이`(방향별). 표고 −4~251m, |경사|>15% 8.9%.
- **강연결요소(SCC)** 정리로 왕복불가 조각 제거 → **완전연결 4,756노드/12,886엣지**.
- **경사비용 구현·검증(β=6):** 오르막 5,519엣지 페널티 → 유효거리 평균 **×1.20**·최대 ×1.55. 동별 순위 견고(초량6동 최고 유지), 집계구 단위로 고지대 강화 → 고지대 과대추정 보정.
- **안전센터 7곳** 정제(대상지 1.5km 이내) + 소방청 데이터로 **구급차 배치 7/7 검증**.

##### ` 축 3 — 이송 목적지 · 완료 `
- 「응급의료법」 제2조제5호의 **권역·지역 응급의료센터**만 후보로 한정(API 15000563).

| 지정 | 병원 | 등급 | 소재 | 경도 | 위도 |
|:---:|:---|:---|:---|:---:|:---:|
| 1 | 동아대학교병원 | 권역응급의료센터 | 서구 | 129.017604 | 35.120006 |
| 2 | 부산대학교병원 | 지역응급의료센터 | 서구 | 129.019222 | 35.101054 |
| 3 | 인제대학교부산백병원 | 지역응급의료센터 | 부산진구 | 129.020572 | 35.146454 |

> **등급 교차검증 완료:** 서구 부산대병원 = 지역응급의료센터 확정(부산 권역 4곳의 "부산대"는 별개 기관 **양산부산대**). 동아대 = 권역. **부산백병원은 2026-11부터 권역 승격 예정**.

##### ` 축 4 — AED (위치 정보) · 완료 `
- 부산 동구 AED **106개** 전수(공공데이터포털 15000652). 요일별 운영시간으로 **야간 접근 판정 → 야간 60 / 주간 46**.
- 야간 커버 집계구 37/78. 저지대 편중(AED 표고 13m vs 고위험 52m) 확인.

##### ` 축 5 — 검증 (실측) · 미확보 `
- 119 출동 기록·질병관리청 급성심장정지조사(2024 생존율 9.2%)로 검증 예정. 정보공개청구 대기.

##### ` 최적배치 — MCLP · 완료 `
- 수요 = 위험>0 & 야간 미커버 41개 집계구, 가중 = 위험도, 반경 150m.
- **신규 15개로 위험가중 86% 커버**(초량6동 7·초량1동 3·좌천동 3·초량2동 2). 경사비용 위험도 위에서도 배분 견고(87%).

## 4. 설치 및 사용 방법

**필요 패키지**
```bash
pip install osmnx geopandas networkx folium shapely pyproj pandas pyarrow scipy requests matplotlib nbformat nbconvert
```
- 공공데이터포털 **응급의료기관(15000563)·AED(15000652)** 인증키 — 반드시 **"일반 인증키(Decoding)"** 사용(Encoding 키는 이중 인코딩되어 오류). `.env`로 관리하며 **git에 올리지 않습니다.**

**분석 실행 (노트북 6단계, 순서대로 — 저장소 루트에서)**
```bash
# 01 병원·AED → 02 도로망 → 03 경사 → 06 연결성 → 10 위험도 → 11 공백·MCLP
jupyter nbconvert --to notebook --execute --inplace code/notebooks/01_병원API_확인.ipynb
# … 02 03 06 10 11 동일
```

**통합 지도 / 경사비용 재산출**
```bash
python code/scripts/생성_통합지도.py        # → outputs/통합지도.html
python code/scripts/경사비용_AED_추정.py     # 경사비용(β=6) 도달지연·후보 비교
```

> 상세 실행·재현 절차는 [`실행방법.md`](실행방법.md) 참조.

## 5. 소개 및 시연 영상

**인터랙티브 결과물:** [`demo/통합지도.html`](demo/통합지도.html) — 레이어 토글형 통합 지도.
- **위험·수요:** ① 집계구 위험도 · ② 75+ 인구(라벨)
- **도로·지형:** ③ 도로 경사(방향별) · 표고 격자(DEM 75m) — 고지대 취약성 시각화
- **시설:** AED 야간/주간 · 안전센터 7곳 · 이송병원 3곳
- **AED 후보지 알고리즘(MCLP):** ⑨ 야간 공백 집계구(수요, 빨강 면) → ⑩ 신규 후보 커버 150m(초록 원) → ⑪ 기존 야간AED 커버(파랑 원). **빨강 공백을 초록 원이 덮도록 후보를 고르는 과정**을 눈으로 확인할 수 있습니다.

> 로컬 실행: `python code/scripts/생성_통합지도.py` → `outputs/통합지도.html`. 웹 열람은 GitHub Pages 또는 htmlpreview로 렌더링.
> 🎬 시연 영상: `작성 필요` — 발표 후 링크 삽입.

## 7. 참여 후기
> ✍️ **중간보고 시점 소감** · 초안(임의 작성) — 최종본은 팀원 각자 수정.

- **정현빈 (팀장/PM)**
  > 문제를 "AED를 어디에 둘까"가 아니라 "왜 필요한 곳과 설치된 곳이 반대인가"로 다시 정의하면서 방향이 잡혔습니다. 지금까지 개발 배경·필요성 근거를 데이터로 갖췄고, 남은 기간에는 최종 발표와 사회적 설득력 강화에 집중하려 합니다.
- **안정환 (시스템/알고리즘)**
  > 도로망 그래프에 경사비용(오르막 페널티)까지 구현해 고지대 취약성을 수치로 드러낸 단계입니다. 다음으로는 도달지연을 실제 '시간'으로 바꾸고(속도 모델) 2m DEM으로 경사 정밀도를 높이는 게 목표입니다.
- **김도윤 (데이터/최적화)**
  > 100m 격자의 '추정'을 집계구 '실측'으로 전환하며 위험 지역 순위가 재편됐고, 안전센터 구급차 배치까지 교차검증했습니다. 남은 과제는 119 출동기록(축5)을 확보해 모델을 실측으로 검증하는 것입니다.
- **이도원 (시각화/문서)**
  > 위험·경사·표고·AED 공백을 한 화면에 겹치는 통합 지도로 복잡한 알고리즘을 '보이게' 만들었습니다. 중간보고 이후에는 시연 영상과 발표 자료로 결과물을 마무리할 계획입니다.
