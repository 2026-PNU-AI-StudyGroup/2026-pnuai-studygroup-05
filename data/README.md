# 데이터 설명서 — 부산 동구 산복도로 AED 최적배치

부산광역시 동구 초량·좌천동(망양로 산복도로) 심정지 대응 **AED 최적 배치** 분석의 데이터셋입니다.
ClickUp 계획의 **5개 축(수요·경사도로망·이송목적지·AED·검증)** 기준으로, 각 데이터의 **출처 → 원본 → 전처리 → 결과**를 정리했습니다.

- 분석 단위: **집계구(실측)** · 인구 기준시점: **2026-06** · 좌표계: 산출물 WGS84(EPSG:4326), 분석원본 EPSG:5186
- 위험도 정의: `정규화(75세+ 인구) × 정규화(도달지연)` — 독거는 제외(A안, 아래 축1 참조)

### 파일별 원본 기준일 (메타데이터)

각 데이터의 **원천 조사·집계 기준일**입니다. 파일 안에도 `집계구인구_기준`·`인구최신화_기준`·`집계구경계_기준`·`AED_기준` 컬럼으로 포함.

| 파일 | 집계구 인구 | 인구 최신화 | 집계구 경계 | AED/병원 |
|---|---|---|---|---|
| 집계구별_고령인구_도달_위험도 | 2024 (SGIS) | 2026-06 (주민등록) | 2025-06-30 (SGIS) | — |
| 집계구별_AED야간공백 | 2024 | 2026-06 | 2025-06-30 | 2026-07 |
| AED_부산동구 | — | — | — | 2026-07 |
| AED_신규배치후보 | 2024 | 2026-06 | — | 2026-07 |
| 이송병원_3곳 | — | — | — | 2026-07 |

- **집계구 인구(2024)**: SGIS 집계구 성·연령별 인구 조사 기준연도
- **인구 최신화(2026-06)**: 주민등록 연령별 인구로 동총량 스케일링한 기준월
- **집계구 경계(2025-06-30)**: SGIS 경계 BASE_DATE (2025년 2분기)
- **AED/병원(2026-07)**: 공공데이터포털 API 조회 시점(갱신분)
- 도로망(OSM)·표고(SRTM 30m, ~2000)는 도달지연 산출에만 사용

## 재현 파이프라인 (노트북)

이 데이터는 아래 6단계 노트북(집계구 실측 라인)으로 생성됩니다.

```
01 병원·AED API → 02 도로망 → 03 경사 → 06 연결성(그래프) → 10 집계구 위험도 → 11 공백·MCLP
```

| 노트북 | 산출 |
|---|---|
| 01 병원API_확인 | 병원 3곳, AED_부산동구 |
| 02·03·06 도로망·경사·연결성 | 완전연결 그래프(도달지연 계산용) |
| 10 집계구_조인세팅 | **집계구별_고령인구_도달_위험도** |
| 11 집계구_공백_MCLP | **집계구별_AED야간공백**, AED_신규배치후보 |

> 구 100m 격자(추정) 라인은 집계구(실측)로 대체되어 아카이브됨.

## 데이터 흐름 한눈에

```
[축3 병원]  API 15000563 ─ 등급필터 ─▶ 이송병원 3곳 ─┐
[축2 도로]  OSM+SRTM ─ 그래프·경사·연결정리 ─▶ 도달지연 ─┤
[축1 인구]  집계구 경계+성연령별 ─ 조인·최신화 ─▶ 75+ 실측 ─┴▶ 집계구별_고령인구_도달_위험도
[축4 AED]   API 15000652 ─ 야간판정 ───────────────────────▶ 집계구별_AED야간공백
                                     위험도 × AED 공백 ─ MCLP ─▶ 신규AED
```

## 축 1 — 수요 (누가 위험한가) · `집계구별_고령인구_도달_위험도`, `집계구별_AED야간공백`

**출처**
- SGIS 자료제공(통계청): 집계구 경계 `bnd_oa_21030_2025_2Q`, 집계구 성·연령별 인구 `21030_2024년_성연령별인구`
- 행안부 주민등록(jumin.mois.go.kr): 행정동 연령별 인구 2026-06

**원본 형태**
| 원본 | 생김새 | 문제 |
|---|---|---|
| 집계구 경계 SHP | 78개 다각형 + `TOT_OA_CD` (좌표만) | 인구 없음 |
| 성·연령별 인구 CSV | long: `연도, 집계구코드, in_age_코드, 값` | 좌표 없음, 2024년, 5명미만 결측 |
| jumin CSV | 행정동, 5세 버킷 | 좌표 없음(행정동 단위) |

**전처리 과정 (변경 흐름)**
1. **조인**: 경계 SHP ⨝ 성·연령별 CSV (`TOT_OA_CD` 키) → 집계구마다 인구 부여
2. **연령 집계**: `in_age` 코드 합산 → 65+(014~021) / **75+(016~021)** / 80+(017~021)
3. **최신화(하이브리드)**: 집계구 2024 분포는 유지하되, jumin 2026-06 동별 75+ 총량으로 **스케일** → `p75_2026` (동별 ×0.81~×1.25, 결측 과소집계도 보정)
4. **도달지연 부여**: 각 집계구 중심을 도로그래프(축2)에 스냅 → 최근접 119안전센터 도로거리 `dist_station_m`
5. **위험도**: `risk = 정규화(p75_2026) × 정규화(dist_station_m)` → `risk_norm`

**독거 제외 이유(A안):** AED는 **목격된** 심정지만 살린다. 독거인이 혼자 쓰러지면 목격자 부재로 AED 접근성과 무관하게 무용 → 독거는 사망위험엔 유효하나 AED 배치 가중으론 방향이 어긋나 제외. (별도 "조기발견 필요 지역" 지표로 분리 예정)

**결과물**
- `집계구별_고령인구_도달_위험도.geojson` / `.csv` — 경계+인구+도달지연+위험도가 **한 파일에 조인된** 형태
- `집계구별_AED야간공백.geojson` — 위 + AED 커버 판정(축4와 결합)

**컬럼 스키마 (`집계구별_고령인구_도달_위험도`)**
| 컬럼 | 설명 |
|---|---|
| `TOT_OA_CD` / `ADM_CD` / `dong` | 집계구코드(14) / 행정동코드(8) / 동명 |
| `oa_area_m2`, `cx`, `cy` | 면적, 중심좌표(5186) |
| `entry_node`, `dist_station_m` | 최근접 도로노드, **안전센터 도로거리(=도달지연)** |
| `p65` / `p75` / `p80` | 연령별 인구 (집계구 2024 실측) |
| `p75_2026` | **75+ 2026-06 최신화값** |
| `f_age` / `f_reach` | 정규화 발생확률 / 도달지연 |
| `risk` / `risk_norm` | 위험도 / 정규화 위험도 |

`집계구별_AED야간공백` 추가 컬럼: `high_risk`(상위30%), `aed_dist_night`(최근접 야간AED 거리), `covered_night`, `gap`(공백), `elev`(표고)

**결과 요약:** 최고위험 초량6동(0.69) > 좌천동 > 초량2동. 공백 16개(초량6동 8 최다). AED 표고 중앙 13m vs 고위험 집계구 52m(저지대 편중).

## 축 2 — 경사·도로망 (어떻게 가는가) · 도달지연 산출에 사용

**출처:** OpenStreetMap(ODbL) 차량 도로망·행정경계·안전센터 / OpenTopoData SRTM 30m 표고

**원본 → 전처리 → 결과**
1. OSM에서 병원·안전센터·경계를 감싼 영역(볼록껍질+1.5km)의 차량 도로망 추출 (원본: 위상 구축된 도로 그래프)
2. WGS84 → EPSG:5186 투영, 노드에 표고 샘플링 → 엣지 경사 계산(방향별)
3. **최대 강연결요소만 유지**(왕복 불가 stub 제거) → 완전연결 그래프
4. → 이 그래프로 집계구별 **도달지연(`dist_station_m`)** 계산 → 축1에 투입

**주의:** 현재 도달지연은 **도로거리(m)** 기준(경사·도로폭·실제 도달시간 미반영). 이 파일셋엔 그래프 원본은 미포함(도달지연 값만 `집계구별_고령인구_도달_위험도`에 반영).

## 축 3 — 이송 목적지 (어디로 옮기는가) · `이송병원_3곳.csv`

**출처:** 공공데이터포털 15000563 (국립중앙의료원 응급의료기관 정보)

**원본 → 전처리 → 결과**
1. API로 부산 구별 응급의료기관 목록 조회 (원본: 기관명 + 등급 + 좌표 XML)
2. **등급 필터**: 「응급의료에 관한 법률」 제2조제5호의 **권역·지역응급의료센터만** 선별 (지역응급의료기관·신고기관 제외)
3. 동구 기준 거리순 상위 3곳 확정

**결과:** 동아대(권역)·부산대(지역센터)·부산백(지역센터). 컬럼: `name, grade, gu, hpid, lon, lat`
※ 동구 내엔 센터급이 없어 전부 인근 구.

## 축 4 — AED (지금 무엇이 있는가) · `AED_부산동구.csv`

**출처:** 공공데이터포털 15000652 (자동심장충격기 정보)

**원본 → 전처리 → 결과**
1. API로 부산 동구 AED 조회 (원본: 좌표 + 요일별 운영시간)
2. **야간 접근 판정**: 월요일 종료시각 ≥2200 또는 24시간 → `night`
3. 집계구별 최근접 야간 AED 거리 → 커버 여부 → **공백**(축1 위험도와 결합, `집계구별_AED야간공백`)

**결과:** AED 106개(야간 60/주간 46). 주요 컬럼: `org, buildPlace, buildAddress, wgs84Lon/Lat, monSttTme~sunEndTme`

## 최적배치 (축1×축4) · `AED_신규배치후보.csv`

**전처리:** 집계구 위험도(축1) × AED 공백(축4) → 공백 집계구 → **greedy MCLP(최대커버리지)** 로 신규 AED 선정
**결과:** 신규 15개로 미커버 위험 86% 커버(초량6동 집중). 컬럼: `rank, dong, TOT_OA_CD, p75_2026, risk_norm, lon, lat`
※ 후보지=집계구 중심 → 실제 설치는 인근 24시간 접근 지점으로 스냅 필요(현장조사).
