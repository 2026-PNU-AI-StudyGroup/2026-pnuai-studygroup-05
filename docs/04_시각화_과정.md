# 04. 시각화 과정 (통합 지도)

분석 산출물을 하나의 **레이어 토글형 인터랙티브 지도**(`demo/통합지도.html`)로 합치는 과정. folium(Leaflet) 기반으로, 위험·지형·시설·AED 후보지 알고리즘을 한 화면에서 켜고 끄며 비교한다.

> 생성 스크립트(로컬): `scripts/생성_통합지도.py` · 결과: `outputs/통합지도.html`
> 개인정보(AED 관리자 실명·연락처)는 지도에 **포함하지 않음**(위치·운영시간만).

---

## 1. 입력 (집계 데이터만)

| 입력 | 출처 | 용도 |
|---|---|---|
| `oa_risk` | 축1·2 | 집계구 위험도·75+ 인구·도달지연 |
| `oa_gap` | 축4 | 야간 공백 집계구(수요) |
| `oa_mclp_new_aed` | 최적배치 | 신규 AED 후보 15 |
| 완전연결 그래프 | 축2 | 도로 경사·표고(노드) |
| AED 106 | 축4 | 야간/주간 위치(개인정보 제외) |
| 안전센터 7·병원 3 | 축2·3 | 마커 |

---

## 2. 레이어 구성

### 2-1. 수요·위험 (choropleth)
- 집계구 폴리곤을 `risk_norm`·`p75_2026`으로 색칠(`branca` 선형 컬러맵). 대표점에 75+ 인구수 라벨(DivIcon).

### 2-2. 도로·지형
- **도로 경사(방향별 부호):** 엣지를 진행방향으로 소폭 오프셋 후 발산형 색(내리막 파랑↔오르막 빨강).
- **표고 격자(DEM 75m):** 노드 표고를 75m 격자 중심에 **`scipy.griddata`(선형+최근접) 보간** → 면으로 표시. *국소 경사가 평탄해도 고지대면 빨강 → "평탄부 오독" 보완.*
- **표시 범위 클립:** 분석 그래프는 원본 유지하되, 지도에는 **집계구 + 400m**만 클립(과도한 도로 범위 축소).

### 2-3. 시설
- AED 야간(파랑)/주간(회색) `CircleMarker`, 안전센터 7(빨강 십자)·병원 3(파란 H) `Marker`.

### 2-4. AED 후보지 선정 알고리즘 (MCLP) — 시각화 핵심
알고리즘을 **눈에 보이게** 3개 레이어로 분해:

| 레이어 | 표현 | 의미 |
|---|---|---|
| ⑨ 야간 공백 집계구 | 빨강 반투명 면 | **수요** (고위험 & 야간 미커버) |
| ⑩ 신규 후보 커버 150m | 초록 원 | MCLP가 **새로 덮는** 범위 |
| ⑪ 기존 야간AED 커버 150m | 파랑 원 | 이미 커버된 곳(대비) |

→ **빨강(공백)을 초록 원이 덮도록 후보를 고르는 그리디 과정**이 지도에서 직관적으로 드러난다. 파랑 원(기존)이 저지대에 몰려 있고 빨강 공백이 산복도로 상단에 남는 "저지대 편중"도 한눈에 보인다.

---

## 3. UX

- 우측 상단 `LayerControl`로 각 레이어 On/Off, 배경 타일(밝게/다크/OSM) 전환.
- 좌측 상단 **레이어 설명 패널**(접기/펼치기), 우측 하단 위험도·경사·표고 **컬러 범례**.
- 폴리곤·도로·마커에 툴팁/팝업(동명·인구·경사·표고·후보 정보).

---

## 4. 실행

```bash
python scripts/생성_통합지도.py     # → outputs/통합지도.html
```
웹 열람은 GitHub Pages 또는 htmlpreview로 렌더링(외부 지도 타일 사용).

---

## 5. 한계
- folium은 외부 타일·CDN을 사용 → 완전 오프라인 아님.
- 후보지는 집계구 중심 기준(실좌표 스냅은 후속). 커버 원은 도보 반경 근사(도로 실제 경로 아님).
- 표고 격자는 SRTM 30m 보간(2m DEM 교체 시 정밀도 향상).
