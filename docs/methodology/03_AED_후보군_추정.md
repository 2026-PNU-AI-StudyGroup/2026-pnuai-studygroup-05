# 03. AED 후보군 추정

집계구 위험도([02. 도로기반 지연 추정](02_도로기반_지연추정.md))와 기존 AED를 겹쳐 **야간 공백**을 찾고, 이를 최대한 덮는 **신규 AED 후보**를 MCLP로 추정한다.

> 입력: 집계구 위험도(경사비용 반영 가능) + AED 106개(야간 60/주간 46)

---

## 1. 야간 커버·공백 판정

**왜 야간인가:** 심정지 대응은 야간이 관건인데, AED 106개 중 야간 접근은 60개뿐(46개 주간 전용).

```python
R = 150                                        # 커버 반경(집계구 중앙 크기 ~157m 근사)
# 집계구 중심 → 최근접 '야간' AED 거리
oa["aed_dist_night"] = cKDTree(야간AED).query(집계구중심)
oa["covered_night"]  = oa["aed_dist_night"] <= R

thr = oa["risk"].quantile(0.70)                # 상위 30% = 고위험
oa["high_risk"] = oa["risk"] >= thr
oa["gap"] = oa["high_risk"] & ~oa["covered_night"]   # 공백 = 고위험 & 야간 미커버
```

- 야간 커버 집계구 **37 / 78**(절반 이하). 공백 **16개**(초량6동 8 최다).
- 표고 확인: 야간 AED 중앙 **13m**(부산역·터미널 평지) vs 고위험 집계구 **52m**(산복도로) → 저지대 편중.

---

## 2. MCLP — 그리디 최대커버리지

**목표:** 한정된 신규 AED로 미커버 위험가중을 최대한 덮는다.

```python
N_NEW = 15
demand = (oa["risk"] > 0) & ~oa["covered_night"]     # 수요 집계구 (41개)
d_w    = oa["risk"][demand]                          # 가중치 = 위험도
cover  = cKDTree(수요중심).query_ball_point(집계구중심, R)   # 후보(집계구 중심)별 덮는 수요

covered, selected = set(), []
for _ in range(N_NEW):
    # 아직 안 덮인 수요의 위험가중 합이 최대인 후보 선택
    best = argmax_c( Σ d_w[j] for j in cover[c] if j not in covered )
    if gain(best) <= 0: break
    covered |= set(cover[best]); selected.append(best)
```

- 후보지 = 집계구 중심(실좌표 스냅은 §4).
- **정확해(ILP) 근사** — 의존성 없이 빠르고, 커버곡선이 완만해 그리디로 충분.

---

## 3. 추정 결과 (거리 vs 경사비용 위험도)

동일 알고리즘을 **거리기준**과 **경사비용 위험도** 두 입력으로 각각 실행:

| | 거리기준 | 경사비용 |
|---|---|---|
| 수요 집계구 | 41 | 41 |
| 15개 커버율 | 86% | 87% |
| 배분(동) | 초량6 7·초량1 3·좌천 3·초량2 2 | 초량6 7·초량1 3·좌천 3·초량2 2 |

**커버곡선(누적 %):** 거리 `10·19·27·35·41·47·53·58·63·68·71·75·79·82·86`, 경사 `10·19·27·34·41·47·52·58·63·67·71·75·79·83·87`.

→ **후보 배분·커버율이 두 방식에서 거의 동일 = 배치안 견고**. 경사비용은 개별 후보의 **우선순위**(상단 집계구 강화)에 반영되며, 총량 배분은 안정적.

## 4. 후보군 계층화·후처리 (추정 보충)

### 4-1. 도달지연(지체) 구간 계층화

각 후보에 소속 집계구의 도달지연을 부여해 **지체 구간**으로 우선순위화 — 늦은 곳일수록 로컬 AED 필요가 크다.

| 구간 | 도달지연 | 배치 우선도 |
|---|---|---|
| 1 근거리 | < 300m | 낮음 |
| 2 중거리 | 300–600m | |
| 3 원거리 | 600–1000m | 높음 |
| 4 초원거리 | ≥ 1000m | 최우선 |

### 4-2. 실좌표 스냅 (제안)

후보지가 집계구 중심이므로, 실제 설치는 인근 **24시간 접근 지점**으로 스냅해야 한다.

```
후보 집계구 중심 → 반경 내 24시간 개방 시설(편의점·파출소·주민센터 옥외함체 등) 최근접 스냅
  · 조건: 야간(24h) 접근 가능 필수
  · 경로당은 주간만 운영 → 옥외 상시개방 함체로 보완
```

산복도로 상단은 24시간 시설 자체가 희소 → **옥외 전용 함체(자체전원·상시개방)** 가 현실적 대안. 실좌표 확정은 공공시설 데이터 + 현장조사 선행(후속).
