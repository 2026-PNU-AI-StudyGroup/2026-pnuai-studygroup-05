## 1. 축1 — 수요/위험군 (집계구 실측)

### 1-1. 원본 3종 (형태가 서로 다름)

| 원본 | 형태 | 한계 |
|---|---|---|
| 집계구 경계 SHP | 78개 폴리곤 + `TOT_OA_CD`(14자리) + geometry(EPSG:5179) | 좌표만, 인구 없음 |
| 성·연령별 인구 CSV | 헤더없는 4열 long: `연도 / 집계구코드 / in_age코드 / 값` | 인구만, 좌표 없음, 2024, 5명미만 결측 |
| 주민등록(jumin) CSV | 행정동, 5세 버킷(거주자_75~79세 등) | 최신(2026-06)이나 행정동 단위(거침) |

- **집계구** = 통계청이 인구 ~500명 되도록 도로·능선 따라 그린 최소 통계구역 → 산복도로 상/하단 구분 가능.
- **in_age 코드:** 014=65~69, 015=70~74, **016=75~79, 017=80~84**, 018=85~89, 019=90~94, 020=95~99, 021=100↑.

### 1-2. 전처리 절차

```python
# (1) 대상 5동 필터: 동구 169개 집계구 → 초량1·2·3·6동 + 좌천동 78개
DONGS = {"21030510":"초량1동","21030520":"초량2동","21030530":"초량3동",
         "21030550":"초량6동","21030700":"좌천동"}
oa = oa[oa["ADM_CD"].isin(DONGS)].to_crs(5186)

# (2) 연령 집계: in_age 합산
AGE = {"p65": range(14,22),   # 65+
       "p75": range(16,22),   # 75+ (주 지표)
       "p80": range(17,22)}   # 80+

# (3) 조인: 경계 ⨝ 인구를 TOT_OA_CD(14자리 코드) 키로 매칭 (공간겹침 아님, VLOOKUP식)
for name, rng in AGE.items():
    codes = [f"in_age_{i:03d}" for i in rng]
    s = df[df["item"].isin(codes)].groupby("oa")["val"].sum()
    oa[name] = oa["TOT_OA_CD"].map(s).fillna(0)   # 5명미만 결측 → 0 (과소집계 한계)
```

### 1-3. 하이브리드 시점 최신화 (2024 → 2026-06)

집계구 통계는 2024 센서스(월별 없음)라, **집계구 내부 분포는 유지**하고 **jumin 2026-06 동별 75+ 총량으로 스케일**만 곱한다. → 시점(2026-06)·정밀도(집계구) 동시 확보 + 5명미만 결측 과소집계도 보정.

```
scale(동) = jumin_75plus_2026(동) / Σ_{oa∈동} p75_2024(oa)
p75_2026(oa) = p75_2024(oa) × scale(동)
```

동별 스케일: 좌천 ×1.03 · 초량1 ×1.12 · 초량2 ×1.25 · 초량3 ×0.81 · 초량6 ×1.15.

**결과:** 초량·좌천 75+ 실측 65+ 10,814 / 75+ 4,781 / 80+ 2,699명.

## 2. 축2 — 도로망·경사 전처리

### 2-1. 그래프 구축 (OSM)

```python
#   → 클리핑 금지: 경계효과로 도달성 과대추정 방지 ("계산은 넓게, 해석은 좁게")
G  = ox.graph_from_polygon(area, network_type="drive", simplify=True)  # 계단 자동 제외
Gp = ox.project_graph(G, to_crs="EPSG:5186")
# 엣지 속성: length, hw_type, width_est(도로유형별 기본폭), amb_passable(폭≥3m)
```

### 2-2. 표고·경사 부여 (SRTM 30m)

```python
# OpenTopoData SRTM 30m API로 노드 표고 (100개씩 배치, 초당1회 제한, 결측→평균)
G.nodes[n]["elev"] = 표고
# 엣지 경사 = 방향별 부호 (오르막 +, 내리막 −), to_undirected 금지
grade(u→v) = (elev[v] − elev[u]) / length(u→v)
```
표고 −4~251m, |경사|>15% 구간 8.9%.

### 2-3. 연결성 정리 (강연결요소)

```python
# 구급차는 가서(출동)+와야(이송) = 양방향 → 최대 강연결요소만 유지
Gc = ox.truncate.largest_component(G, strongly=True)   # SCC 61→1, 왕복불가 72노드 제거
# 결과: 완전연결 4,756노드 / 12,886엣지
```

### 2-4. 안전센터 정제 + 구급차 검증

- OSM `fire_station`을 넓게 받으면 인근 구까지 13곳(최대 3.2km) → 동구 심정지에 비현실적.
- **대상지 1.5km 이내 7곳만** 출발지로 유지 + 소방청 구급차 데이터로 **7/7 배치 검증**.
