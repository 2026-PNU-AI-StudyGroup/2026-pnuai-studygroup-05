# 02. 도로기반 지연 추정 (경사비용 보충)

전처리된 완전연결 도로 그래프 위에서 각 집계구의 **도달지연**(안전센터 → 현장 최단 이동비용)을 추정한다. 기본 거리기준에 더해 **경사비용(오르막 페널티)** 을 구현·검증했다.

> 입력: [01. 데이터 전처리](01_데이터_전처리.md)의 완전연결 그래프(4,756/12,886) + 안전센터 7곳

---

## 1. 기본 도달지연 (거리 기준)

각 안전센터에서 Dijkstra로 모든 노드까지 최단 도로거리를 구하고, 집계구 중심을 최근접 노드(`entry_node`)에 스냅해 최솟값을 취한다.

```python
station_nodes = [n for n,d in G.nodes(data=True) if d["node_type"]=="station"]  # 7곳
oa["entry_node"] = nearest_nodes(G, 집계구 중심)
best = {}
for s in station_nodes:
    for n, d in single_source_dijkstra_path_length(G, s, weight="length").items():
        best[n] = min(best.get(n, inf), d)
oa["dist_station_m"] = oa["entry_node"].map(best)
# 이상치(일방통행 far-corner 우회 7km 등) 95백분위 클립 → 정규화 왜곡 방지
reach_cap = dist_station_m.clip(upper=quantile(0.95))
```

### ⚠ 문제: 고지대 접근성 과대추정

`weight="length"`는 경사를 무시한다. 그래서 **가파른 고지대라도 도로상 가까우면 접근성이 좋게(위험 낮게) 과대추정**된다 — 산복도로 상단은 실제 구급차 등판 시간이 훨씬 큰데도.

---

## 2. 경사비용 보충 (구현)

### 2-1. 유효거리 모델

엣지 비용을 **진행방향 오르막에만 페널티**를 준 유효거리로 대체한다. 내리막·평지는 그대로(1배).

```
cost(u→v) = length(u→v) × ( 1 + β · max(0, grade(u→v)) )
```

- `grade`는 방향별 부호(오르막 +) → Dijkstra가 안전센터→현장 방향으로 타면 **등판 구간만** 비용 증가.
- β = 6 (기본), 민감도 4/6/8. 가정 최소로 "거리형" 단위 유지.

### 2-2. 실제 구현 코드

```python
BETA = 6.0
for u, v, k, d in G.edges(keys=True, data=True):
    L = float(d.get("length", 0) or 0)
    g = d.get("grade"); g = g if (isinstance(g, float) and g == g) else 0.0
    d["cost"] = L * (1.0 + BETA * max(0.0, g))          # 오르막만 페널티

best = {}
for s in station_nodes:
    for n, dd in single_source_dijkstra_path_length(G, s, weight="cost").items():
        best[n] = min(best.get(n, inf), dd)
oa["reach_slope"] = oa["entry_node"].map(best)
oa["f_reach_slope"] = minmax( reach_slope.clip(upper=quantile(0.95)) )
oa["risk_slope"]    = minmax( f_age × f_reach_slope )   # f_age(75+)는 그대로
```

### 2-3. 검증 결과 (실측)

- 오르막 엣지 **5,519 / 12,886**에 페널티 적용.
- **유효거리 증가배율**(경사/거리): 평균 **×1.20**, 중앙 ×1.19, **최대 ×1.55**(경사로 55% 더 멂).

**동별 위험도 (거리 → 경사비용):**

| 동 | 거리기준 | 경사비용 | 순위 |
|---|---|---|---|
| 초량6동 | 0.679 | 0.674 | 최고 유지 |
| 초량2동 | 0.423 | 0.395 | |
| 좌천동 | 0.411 | 0.391 | |
| 초량1동 | 0.390 | 0.364 | |
| 초량3동 | 0.088 | 0.076 | |

**해석:**
- **동별 순위는 견고**(초량6동 최고 유지) → 결과가 β에 민감하지 않음 = 결론 robust.
- **집계구 단위**에선 경사비용이 **초량6동 고지대(산복도로 상단) 집계구를 상위로 더 부각**(위험 상위 1·2위가 초량6동). 거리기준에서 2위였던 초량2동(평지 인접)은 밀림.
- 즉 경사비용은 **"가파른 상단일수록 도달 불리"** 를 정량 반영 → 고지대 과대추정 편향을 보정하고, 프로젝트 논지(산복도로 상단 취약)를 **강화**한다.

## 3. 파라미터·한계

| 항목 | 값 | 비고 |
|---|---|---|
| β (오르막 페널티) | 6 | 민감도 4/6/8 |
| Dijkstra 가중 | `cost`(경사비용) / `length`(비교용) | 양쪽 저장 |
| 이상치 클립 | 95 백분위 | far-corner 우회 제거 |
| 표고 | SRTM 30m | 2m DEM 정밀화 예정 |
